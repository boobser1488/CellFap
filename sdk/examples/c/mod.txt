name Водоворот (нативный пример на C)

description Нативный мод на C: закручивает воду в чашке водоворотом, залечивает раны фагоцитов,

setting сила число 0.02 0 0.2 Сила водоворота (мкм за тик)
setting лечение флаг 1 Фагоциты залечивают раны
setting пауза флаг 0 Остановить физику игры (мод пропускает тики)
setting сбой флаг 0 Проверка: after_step вернёт ошибку (мод выключится)
