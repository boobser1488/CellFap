# CellFap

Песочница эволюции клеток — клон **Cell Lab: Evolution Sandbox** на **C++20 + Vulkan + Dear ImGui**
для Windows и Android. Интерфейс на русском.

## Возможности

- **24 типа клеток**: 18 типов оригинала (фагоцит, флагеллоцит, фотоцит, деворoцит, липоцит, кератиноцит,
  буйоцит, глюеоцит, вироцит, нитроцит, стереоцит, сенсоцит, миоцит, нейроцит, секроцит, стемоцит, гамета,
  цилиоцит) и новые: электроцит, книдоцит, хроматоцит, люминоцит, цистоцит, хватоцит.
- **Редактор генома**: до 128 мод, деление «пальцем» (призраки потомков), полный и простой режимы,
  программы и сигналы S1–S8, живое превью развития по стадиям, отмена/повтор, браузер геномов с миниатюрами.
- **Субстрат**: свет и смена дня и ночи, пища, вязкость, трение, солёность, нитраты, гравитация, радиация,
  старение, заражение, механический урон, генофонд, крышка чашки, стены (редактор карты).
- **Микроскоп**: 10 инструментов — диагностика, синтезатор, оптический пинцет, бустер, удаление, электрод,
  генная игла, игла для веществ, редактор карты, адгезин. Скорости: заморозка / медленно / наблюдение /
  инкубация (симуляция идёт в отдельном потоке и не снижает частоту кадров).
- **Мягкие клетки**: контур из 32 упругих спиц — клетки вдавливаются друг в друга общим швом, сминаются о
  стекло и стены; адгезин виден волокнами на стыке. Всё рисуется аналитически (SDF) — чётко на любом зуме.
- **Многоклеточные существа** (нематоды, рыбы, черви-гиганты, гидры, пиявки, тихоходки…) описаны на языке
  dypt (`scripts/organisms.dpt`), плавают волной сокращений мышц и ресничками, ищут пищу.
- **Задания** (20 уровней) и **эксперименты** (17 готовых чашек).
- **Файлы**: свои форматы геномов и чашек, импорт геномов и чашек Cell Lab, экспорт генома в формат Cell Lab;
  «Поделиться» — файл с сообщением для мессенджера.

## Сборка для Windows (MSYS2 UCRT64)

Dear ImGui подключён подмодулем, поэтому клонируйте вместе с ним:

```bash
git clone --recursive https://github.com/boobser1488/CellFap.git
```

```bash
pacman -S mingw-w64-ucrt-x86_64-{gcc,cmake,ninja,vulkan-headers,vulkan-loader,glfw,shaderc,zlib}
cmake -S . -B build/release -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build/release
```

Результат — `build/release/CellFap.exe` (нужен драйвер с Vulkan 1.1). Существа на dypt собираются в
`organisms.dll`, если найден компилятор dypt (переменная `DYPT_HOME`); без него игра тоже собирается.

Дополнительные программы: `evolve.exe` — ночная эволюция без графики, `make_icon.exe` — иконка приложения,
`export_organisms.exe` — встраивание существ в сборку для Android.

## Сборка для Android

Нужны Android SDK (NDK, build-tools, platform, cmake) и JDK; Gradle не нужен:

```bash
bash android/build_apk.sh
```

Результат — `build/android/CellFap.apk` (arm64-v8a, Android 8.0+, Vulkan 1.1). На телефоне — свой интерфейс:
закреплённые панели, жесты (касание — инструмент, два пальца — сдвиг и масштаб), выбор ориентации,
открытие файлов из мессенджеров и «Поделиться».

## Управление на ПК

| Клавиша | Действие |
|---|---|
| Колесо | зум к курсору |
| ПКМ / СКМ, WASD | перемещение |
| Пробел | заморозка / продолжение |
| 1–0 | инструменты |
| Tab | окно «Клетка» |
| F | следить за клеткой |
| Del | удалить выбранную клетку |
| Home | показать всю чашку |
| F2–F6 | разделы |
| F11 / F12 | полный экран / снимок в папку `screenshots` |
| Ctrl+Z / Y / S | отмена / повтор / сохранить геном |
| F1 | справка |

## Архитектура

- `src/sim` — симуляция без графики: равномерная сетка, параллельные фазы (подготовка → контакты →
  адгезины → интеграция → решатель контактов), последовательные события (деления, смерти, заражение).
- `src/core/jobs.hpp` — пул потоков для параллельных фаз.
- `src/render` — Vulkan: инстансинг (один вызов отрисовки на слой), SDF-шейдеры клеток.
- `src/app.cpp` — цикл, поток симуляции, камера, интерполяция между тиками, мягкие контуры.
- `src/ui*.cpp` — интерфейс: ПК (`ui.cpp`, `ui_genome.cpp`, `ui_challenges.cpp`), телефон (`ui_mobile.cpp`),
  файлы и браузер геномов (`ui_files.cpp`).
- `android/` — NativeActivity с небольшим Java-классом (`android/java`) и подмножеством GLFW (`android/shim`).
- `third_party/imgui` — Dear ImGui (MIT).
