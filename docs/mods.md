# Модификации CellFap

Модификация — это скрипт на dypt с описанием. Она добавляет в игру геномы и
программы для сигнальных клеток, а пока работает, следит за чашкой: подсыпает пищу и меняет условия.
Модификации включают, выключают и настраивают в окне **«Модификации»**: меню «Окна» или «Настройки» →
«Открыть «Модификации»».

> В игре «моды» уже означают режимы клеток в редакторе генома, поэтому окно называется «Модификации».

## Где лежат

Папка `mods` рядом с игрой (на телефоне — в данных приложения). Каждая модификация — либо папка:

```
mods/
  example/
    mod.txt          описание и настройки
    mod.dpt          скрипт
    genomes/...      любые свои файлы: геномы, программы, текст
    programs/...
```

либо один файл `.cfmod` — та же папка, упакованная для обмена. При первом запуске игра кладёт в `mods/example`
пример (выключенный). Файл `.cfmod` можно открыть игрой («Открыть файл…», «Поделиться» на телефоне, кнопка
«Добавить .cfmod…» в окне) — он скопируется в `mods` выключенным: чужой скрипт запускаете вы сами.

## mod.txt

Строки «ключ значение», `#` — комментарий.

| Ключ | Что это |
| --- | --- |
| `id` | имя для `settings/mods.ini` (буквы, цифры, `_`, `-`); обязателен и должен быть уникальным |
| `name` | название в окне; обязателен |
| `version`, `author` | для окна |
| `description` | описание; несколько строк `description` склеиваются |
| `tick N` | вызывать `тик()` каждые N тиков симуляции (400 тиков — час игрового времени); без строки — не вызывать |
| `setting …` | настройка, которую игрок меняет в окне (ниже) |

Настройки:

```
setting <ключ> число <по умолчанию> <мин> <макс> <подпись>
setting <ключ> флаг  <0|1> <подпись>
setting <ключ> выбор <по умолчанию> <вариант,вариант,...> <подпись>
```

Число с целыми границами показывается целым ползунком и приходит в скрипт целым (`int`) — его можно ставить в
`for k = 1 to n`. Значения, которые игрок поменял, сохраняются в `settings/mods.ini`.

## mod.dpt — точки входа

Все необязательны, но хотя бы одна из первых двух нужна, иначе модификация ничего не делает.

| Функция | Когда |
| --- | --- |
| `загрузка()` | один раз при включении: добавить геномы и программы, подготовить своё состояние |
| `тик(состояние)` | каждые `tick` тиков; `состояние = [часы, клеток, пищи, тик]` |
| `настройки_изменены()` | игрок поменял настройку в окне |
| `выгрузка()` | при выключении |

Переменные верхнего уровня файла живут, пока модификация включена (присваивание внутри функции меняет глобальную
переменную, если она уже задана наверху файла).

## Функции игры

| Функция | Что делает |
| --- | --- |
| `журнал(...)` | строка в журнал модификации (окно «Модификации»); доводы подряд, как `print` — он тоже пишет в журнал |
| `сообщение(текст)` | всплывающее сообщение на экране |
| `настройка(ключ)` | значение настройки: число, `true`/`false` или выбранный вариант строкой |
| `файл_мода(путь)` | текст файла из папки модификации |
| `случайное()` | число от 0 до 1 |
| `добавить_геном(название, файл)` | только в `загрузка()`: геном (файл `.genome.txt` из модификации или сам текст генома) — в браузере геномов, вкладка «Модификации» |
| `добавить_программу(название, файл)` | только в `загрузка()`: программа сигнальной клетки (файл `.dpt` или текст) — в редакторе программ, «Вставить пример» |
| `добавить_пищу(x, y, масса?)` | только в `тик()`: порция пищи в точке (мкм от центра чашки), масса 0.01–2 (по умолчанию 0.3); до 500 за вызов |
| `узнать(имя)` | в `тик()` и `настройки_изменены()`: `часы`, `клеток`, `пищи`, `тик`, `радиус` и параметры ниже |
| `задать(имя, значение)` | только в `тик()` и `настройки_изменены()`: параметр чашки (значение ограничивается диапазоном) |

Параметры для `узнать`/`задать`:

| Имя | Диапазон |
| --- | --- |
| `свет` | 0–2 |
| `питание` | 0–15 (скорость появления пищи) |
| `радиация` | 0–0.09 |
| `вязкость` | 0–150 |
| `гравитация` | 0–1 |
| `солёность` | 0–1 |
| `нитраты` | 0–1 |
| `день` | 0–48 (длина суток в часах, 0 — вечный день) |
| `направление_света` | радианы |

Всё, что скрипт меняет, игра собирает и применяет после того, как функция вернулась: пока скрипт работает, чашку
он не трогает.

## Ограничения и безопасность

- Нельзя: `import`, `extern`, `from`, работа с файлами (`read`, `write`, `append`, `exists`), внешние библиотеки
  (`load_bin`, `call_bin`, `call_at`), память (`malloc`, `raw_*`, `peek`, `poke`, `mem_*`), потоки, `sleep`, `exit`,
  ввод с консоли, `async`/`await`. Такой скрипт не запустится, а сборщик его не упакует. Стандартные модули dypt
  (они подключаются через `import`) недоступны.
- Вызов, который думает дольше 0.5 с, выключает модификацию (сторож); другие перезапускаются.
- Пять ошибок в `тик()` выключают модификацию; причина — в окне.
- Все модификации вместе получают до 8 мс на тик симуляции; что не успело, ждёт следующего тика.
- До 64 геномов и 64 программ на модификацию; `mod.dpt` — до 64 КБ; модификация целиком — до 16 МБ.

## Сборка .cfmod

В окне — кнопка «Собрать .cfmod» у модификации-папки: файл появится рядом с папкой, на телефоне сразу откроется
«Поделиться». Или из командной строки (собирается вместе с игрой):

```
modpack mods/example                  собрать mods/example.cfmod
modpack mods/example out.cfmod        собрать в свой файл
modpack --check mods/example          проверить, ничего не записывая
modpack --list example.cfmod          что внутри
modpack --unpack example.cfmod папка  распаковать
```

Сборщик проверяет `mod.txt` (`id`, `name`, настройки) и `mod.dpt` (запрещённые функции). Формат файла:
`CFMOD1\n`, размеры, затем файлы, сжатые zlib (`src/sim/modpack.cpp`).

## Пример

`mods/example` в репозитории: геном «Розовая водоросль», программа «Мигалка», пищевой дождь с настройками
(сколько порций, где) и свет, обходящий чашку по кругу.

```dypt
дождей = 0

function загрузка() {
    добавить_геном("Розовая водоросль", "genomes/pink_alga.genome.txt")
    добавить_программу("Мигалка", "programs/blinker.dpt")
}

function тик(состояние) {
    if настройка("дождь") {
        for k = 1 to настройка("порций") {
            добавить_пищу((случайное() - 0.5) * 400, (случайное() - 0.5) * 400, 0.3)
        }
        дождей = дождей + 1
    }
}
```

Правите `mod.dpt` — нажмите «Перезапустить» в окне: файлы перечитаются с диска.
