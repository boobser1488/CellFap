description устраивает пищевой дождь и меняет свет по кругу.
# тик() вызывается каждые 100 тиков симуляции (400 тиков — час игрового времени)
tick 100
# setting <ключ> число <по умолчанию> <мин> <макс> <подпись>
setting порций число 8 0 60 Порций пищи за один дождь
# setting <ключ> флаг <0|1> <подпись>
setting дождь флаг 1 Пищевой дождь
# setting <ключ> выбор <по умолчанию> <вариант,вариант,...> <подпись>
setting где выбор везде везде,центр,край Где идёт дождь
setting свет_по_кругу флаг 0 Свет обходит чашку по кругу
